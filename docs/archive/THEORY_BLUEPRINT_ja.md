## 2. 共通算術

L の正規形は `(b,e_1,…,e_n)`、`b : ℤ`、`0≤e_i<p_i`。加算は e_i の繰り上がりを b に加える。抽象商群とこの具体モデルの同型を証明すれば、その後の根の計算は具体モデルでよい。

```
N = lcm(p_i)
k = N − Σ_i N/p_i        -- ℤ
rootExists(a,p) ↔ a ∣ k ∧ gcd(a,N)=1
```

`aσ_i ≡ −1 (mod p_i)`、`0≤σ_i<p_i`、`b_i=(aσ_i+1)/p_i`、`b=(1−Σ b_i)/a` とし、τ=`b c+Σσ_i x_i`。割り算の前に divisibility、負の値が出る b では整数除法を使う。存在を有限探索で決定するだけでなく、根の一意性を torsion と Bézout で証明する。

Y_i=X_i^{p_i} とすると T の各成分は一つの剰余単項式に Y の斉次多項式を掛けた空間であり、ΣY_i=0 で一変数をモニック消去できる。ここから有限自由基底と Hilbert 恒等式を構成する。幾何学的な stacky Proj は初版では使わない。

## 3. 三変数の計算の核

指数は α,β,γ≥2。a は Gorenstein パラメーターなので指数に a,b,c を再利用しない。

|tag|f|未約分重み w|h|
|---|---|---|---|
|I|x^α+y^β+z^γ|(βγ,αγ,αβ)|αβγ|
|II|x^αy+y^β+z^γ|(γ(β−1),αγ,αβ)|αβγ|
|III|x^αy+xy^β+z^γ|(γ(β−1),γ(α−1),αβ−1)|γ(αβ−1)|
|IV|x^αy+y^βz+z^γ|(γ(β−1)+1,α(γ−1),αβ)|αβγ|
|V|x^αy+y^βz+z^γx|(γ(β−1)+1,α(γ−1)+1,β(α−1)+1)|αβγ+1|

初版は五つの tag と `2≤α,β,γ≤a+6` の立方体をそのまま走査する。`gcd(w)=1` と `h=a+sum w` を満たすものだけを残す。gcd を割った重みでフィルターするのではなく、未約分重みが原始であることを使う。全ての対象にこの形の代表があることは別の深い証明である。

この核を単独に実装して finite-filter の一般定理から健全性・完全性をまず証明する。約数分解による高速版は二番目に実装し、まず基準版との全入力での等価性を証明する。指定された範囲で一致しただけでは高速版を正しいとはしない。

### 3.1 指数上界を形式化する

I: α≤β≤γ とできる。α=2なら `(β−2)(γ−2)=a+4`。α≥3なら `γ=(αβ+a)/(αβ−α−β)≤3+a/3`。

A=α−1、B=β−1、t=γ−1 と置くと他は

```
II:  t A B = A+B+a+1
III: t A B = A+B+a
IV:  B(t A−1)=a+1
V:   t A B = a+1.
```

A=1またはB=1を先に分岐し、残りで `(A−1)(B−1)` の上界を使う。`a+6` という粗い同一上界で十分。`nlinarith` が自動で全て解くと仮定せず、正因子と整除の補題に分ける。

### 3.2 明示的な根環への写像

以下の p の順序に対して M と M0 を取る。

|tag|p|M=(M1,M2,M3)|M0|
|---|---|---|---|
|I|(α,β,γ)|(X,Y,Z)|1|
|II|(α,γ(β−1),γ)|(X,Y^γ,YZ)|Y^γ|
|III|(γ(α−1),γ(β−1),γ)|(X^γ,Y^γ,XYZ)|X^γY^γ|
|IV|(α,γ(β−1)+1,α(γ−1))|(XZ,Y^γ,YZ^α)|Y^γZ^α|
|V|(β(α−1)+1,γ(β−1)+1,α(γ−1)+1)|(X^βZ,XY^γ,YZ^α)|X^βY^γZ^α|

f(M)=M0(ΣX_i^{p_i})、および `a deg_L(M_i)=w_i ω` を整数で証明する。torsion を含む L 内での等式が必要なので有理次数の一致だけでは不足する。原稿の付録 C 行列はこのための整数恒等式証明書であり、`ring` 等で証明できる候補である。

135本の係数恒等式の Python 検査を、パラメーターを変数とした Lean の等式へ置き換える。単項式写像が well-defined なのと同型なのは別で、局所化した単射性・整性/正規性・Hilbert 関数で同型を示す原稿の依存を監査する。

### 3.3 本当の難所：任意の根環からの完全性

v02 の経路は

```
実際の R → 斉次基底 → Hilbert 相反式・一次の極
 → signature の復元 → 三頂点の七支持 → 分岐二型の排除
 → 可逆表示の原始化 → 元の T 内の単項式同型
 → weight-key による次数付き同型判定
```

最初から R の式が可逆だと仮定しない。`lem:coordinatepole` の仮定、座標線に式が恒等的に消える場合、`lem:fourterm` の係数選択、`prop:mutation` の零除算と例外場合を重点監査する。種数・スタックの結果を名前だけ変えて暗黙に戻さない。

極は有理関数に `(1−t/ζ)` を掛けた後の評価。`1−ζ^(−a)` の非零性を先に証明する。初版では C 内の roots of unity と有限和を使い、複素解析の留数は使わない。円分体による代替は、本当に依存が小さくなる場合だけ選ぶ。

同じ重みの根環について同型になることを証明してから重複除去する。ヒルベルト関数が同じという一般の主張に変えない。

## 4. 高次元の完全な整数再帰

n≥4 の対象は、相異なる昇順 p_i≥2、pairwise coprime、および

```
P_full − Σ_i P_full/p_i = a
```

を満たすもの。定義式は Σ X_i^{p_i}。R=T、最大根という帰結を別途証明する。

再帰には分数を保存する必要はない。prefix について

```
P = product(prefix) > 0
A = P − Σ_{q in prefix} P/q
remaining = n − prefix.length
```

を保持する。`A>0` なら残りの最小 q の上界は

```
q ≤ floor(((remaining+a)*P)/A).
```

次の q を選ぶと

```
P' = P*q
A' = A*q − P.
```

初期値は P=A=1。順序と gcd を検査し A'≤0 の枝を除く。最後の一座標なら `q=(a+P)/A` と決まり、整除・順序・gcd を検査する。最終の defect 等式も確認する。

再帰は `remaining` の構造的帰納法で停止させる。探索用の意味不明な fuel は置かない。正しい解の全ての prefix は A>0 でこの上界を満たすことを帰納的に示し、葉の式 `A*q−P=a` から健全性を示す。計算には Nat で等式を組み替える版または Int の A を使えるが、除算ガードを先に証明する。

### 4.1 環論側は別途必要

孤立性から pairwise coprimality を示すため、二座標の共通因子 s>1 があると完備局所環が
`C[[t_1,…,t_(n−3),U,V,W]]/(UV−W^s)`
になる原稿の議論がある。ここは整数再帰からは出てこない。完備化の既存ライブラリ負担が大きければ、非零座標を局所化した明示的不変環と接空間次元で直接非正則性を示す代替を研究する。代替が閉じなければ元の必要な一般補題を実装する。単に「この補題を仮定する」に逃げない。

pairwise coprime が得られたら、純冪生成元と二変数支持の数え上げにより、埋込み次元 n から R=T を導く。この枝は gcd forest の一般分類に依存させない。

## 5. 証明書方式が有効な部分

健全性の孤立臨界点の検査には、各 i について正整数 k_i と多項式 A_ij を持ち

```
z_i^(k_i) = Σ_j A_ij * (∂_j f)
```

という恒等式を証明すれば十分である。この十分条件を Lean 内で証明してから、外部計算が候補 A_ij を作ることは許される。全ての族について均一な証明を作れるならなお良い。原点が実際に臨界点であることも別に確認する。

この方式は一般の正規性・商環同型・完全性の代わりにはならない。出力を候補箱全体に対する verified checker で検査する場合、未採択候補や再帰木の網羅性まで確認しなければならない。
