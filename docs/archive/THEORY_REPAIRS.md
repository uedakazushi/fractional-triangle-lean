## 実装に合わせた証明の置換

* `lem:exponentbound`: I の指数のソートを省き、任意の二指数 x,y≥2、(x,y)≠(2,2) について
  1≤xy−x−y と xy≤6(xy−x−y) を先に証明する。これを三座標に適用する。
  II/III は tAB=A+B+c の全正整数解の三因子を c+2 で抑える一般補題へ分解した。
  IV/V は正因子の積からの上界。元命題より強く、原始性を仮定しない。
  対応: `Cox.exponent_bound`。
* `lem:coxidentities` と付録の135恒等式: 五型を列挙型とし、行・列を Fin 3 で量化。
  `ring` が生成した証明項で各整数恒等式を閉じた。`Cox.lattice_degree` は
  整数係数の恒等式を任意のアーベル群に移す。群の有理化は使わない。
* `eq:recursivebound`: 分数の不等式に代えて、積 P と省略積和 C の整数補題を使う。
  q C(ps)≤length(ps) product(ps) と完了方程式 A product(ps)=a+P C(ps)
  から床上界を導く。証明の進捗はSTATUSとビルドログを参照。

## 早期の危険箇所監査

1. `lem:rootpole`: 有限初項の修正は単純極係数に寄与しない。Fourier の符号は
   σ⁻¹≡−a と整合する。分母非零には根存在条件 gcd(a,pᵢ)=1 が必要。
2. `lem:coordinatepole`: 座標面制限の非零性は f の既約性に依存する。
   二重分母零では gcd(A,B)|h と gcd(gcd(A,B),C)=1 が必要。頂点での微分条件も必要。
   これらを省略した一般の重み公式としては使わない。一般証明は未形式化。
3. `lem:fourterm` / `prop:mutation`: 同じ重みの別方程式を作るだけでは元の環との
   同型は出ない。v02末尾の証明はsignature復元→同じp→根一意性→単射を用いる。
   この依存関係を維持する。有限な実験による代用はしない。
4. `prop:pairwise`: stabilizer と全群は区別する。共通因子の二座標零点層が非空で
   正次元であるために n≥4 が必要。局所モデルの接空間次元と非正則性は後述のとおり
   形式化済み。完備化交換・不変環同型による根環との接続は未形式化。
5. `lem:coxlocal`: 関係式の保存はwell-defined性のみ。Laurent格子指数、指標分離、
   半不変主イデアルの不変部分、有限群平均、局所化単射性がそれぞれ必要。

現時点で主分類を否定する反例は確立していない。同時に、この監査を一般の環論補題の
証明と見なしてもいない。未完部分は証明義務表に残し、axiomにはしない。

## 根の存在と高次元実現の追加形式化

prop:rootの十分性はBézoutを直接用いた。sa+tN=1、k=auなら
τ=sω+tu c と置く。Nω=kcを実群内で証明しaτ=ωを得る。正規形と
各p_iとの互いに素性からa倍の単射性を証明するのでtorsionを除去しない。

高次元族の実現ではP=prod p、w_i=prod_{j≠i}p_j、a=P−Σwを使う。
既に得たa倍の単射性からPτ=c。y_i=x_i−w_iτならp_i y_i=0、Σy_i=0。
各p_iがpairwise coprimeなので、w_iを掛けて他のy_jを消し、
p_iとw_iのBézoutからy_i=0。従ってR=Tであり、
全単項式次数の比較から全次数を保つ実AlgEquivを構成できた。
これは実現方向の証明であり、任意の孤立超曲面根環から数値条件を導く逆方向は未証明。

## 最小性と局所モデルの非正則性

最小性は、原点イデアルmに対してf∈m²を証明し、商の余接空間をℂ^nへ同型化する。
任意の別の代数生成元系は定数を引いて原点保存にできるため、生成元数の下限nが得られる。
従って、表示にある「一次項なし」は実際の最小生成元数と接続された。

app:localの非正則性部分は、完備形式冪級数環を先に構築せず、実多項式商の原点での
局所化に対して証明した。極大イデアルの冪の商は局所化で保たれるので、余接空間は
変わらない。非零関係式によるKrull次元上界と比較して非正則性を得る。
UV−W^sのモデルにはこの一般定理を適用済みである。

この置換だけではprop:pairwiseは閉じない。元の根環からこの局所モデルへの同型、
安定化群と全群の区別、非零点層の存在、孤立性との矛盾への輸送が残る。

## 有限自由表示と形式的Hilbert相反式

原稿prop:freeの基底再編を、実際の乗法と多項式係数の作用が一致することを証明して実装した。
先にC基底から多項式加群基底を組み立て、その基底の一つの係数を読むことで代入写像の
単射性を得る。この順序により、まだ証明していない整域性を代数的独立性の根拠に使わない。
単射性の後に、多項式環と実部分代数の同型を通して係数を移す。

相反式は実Hilbert係数→形式冪級数→Laurent級数内の有理関数表示の順に証明した。
1−t^Nの定数係数は1なので分母は零ではない。t⁻¹への置換はRatFuncで行う。
大きい次数の漸近や解析的極の比較を仮定していない。
この段階でprop:freeが閉じた。cor:numericalの超曲面表示との比較は、以下の続行で数値公式まで閉じた。


## 数値的次数差を多項式の次数比較で導く

任意の非零斉次関係式fについて、次数ごとの乗法単射と商写像の核を同定した。
これにより実商成分の次元からH∏(1−t^w_i)=1−t^hが得られる。
根箱分子Bは補元対合で対称になり、dim R_0=1から定数係数と最高係数が1とわかる。
従ってdeg B=a+(n−1)N。二つのHilbert式を掛け合わせて得た多項式恒等式の次数を比較し、
h=a+Σwを導いた。これは有理関数体の反転写像や標準加群の同定を要しない経路である。

原始性はcarry≥mμ−nとμ>0から全十分大次数の非消滅を示し、共通因子g>1なら

## 漸近計算を有限全単射による数え上げへ置換

signatureの長さをr、N=lcm(p)、Nτ=ucとする。箱座標を各p_iで割った商と剰余に分ける。
次数mτの剰余ベクトルはm mod Nで決まり、異なる剰余次数は異なるベクトルを与える。
これはaσ_i≡−1 mod p_iと正規形の一意性から実次数群のまま証明する。

固定した次数剰余ごとにr−1個の商座標d_i∈{0,…,u−1}があり、条件は
Σd_i≡carry(m) mod uのみ。最後の一座標が一意に決まり、個数はu^(r−2)。
全N個の剰余次数を合わせて |RootBox|=N u^(r−2) を得る。
実RootBoxとの全単射の全射性ではmをNで割り、単射性では剰余ベクトルの単射性を使う。
整数根次数が負でないことは、箱単項式の非負有理次数とμ>0から別途証明する。
従って漸近式や周期ごとの平均を新たな仮定に置かず、h/Πw=μ^(r−2)まで到達した。

## 整拡大からの次元

実有限自由加群性から実多項式部分環A⊆R上の整拡大性を得る。
IncomparabilityでRの素イデアル鎖をAに収縮し、lying overとgoing upでAの鎖をRへ持ち上げる。
これでdim R=dim A=r−1。根環の整域性・正規性をこの証明に前借りしない。

## 有限次数商を有限群の位数計算に先行させる

L/ℤτではuc=0なので、整数正規形のc係数をmod uへ還元できる。
有限集合Fin u × Π_i Fin p_iからの全射で商の有限性を示した。
位数の正確な式やλ(L)の像を先に仮定せず、固定mathlibの有限アーベル群双対性を適用し、
複素指標の有限性と非零次数の分離を得る。正確な群位数と座標表示はまだ残る。


## 最終実装の原稿との対応と不要になった補題

I–III はモニック商と生成、IV は先頭指数の単射と正次数帰納、V は Fermat 拡大の
Eisenstein 判定と次元降下から実商写像の同型を証明した。Hilbert 一致だけを同型としない。
旧設計の M02 と C01 の一般版は最終定理の仮定にも依存にも入らない。
