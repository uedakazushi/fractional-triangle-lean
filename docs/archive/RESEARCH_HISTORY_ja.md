# 研究の到達点・訂正・非目標

## 優先順位

ユーザーが現在選んだ対象は孤立超曲面 canonical-root 環だけである。現行本文は `research/current/canonical_root_isolated_ja_v02.tex`。既存の証明・計算を記した資料の source of truth であって、正しさが検証済みという意味ではない。原稿の論理に欠落を見つけたら、その補修を証明対象として追跡する。

旧 `fractional_triangles_v04` は三変数の automatic Cox-invertibility と全 index の約数分類。旧 `higher_canonical_roots_v03` は高次元の rigidity、gcd forest、完全交差、孤立 locus の漸近。v05 は三変数の有限判定を初等化した途中稿。v02 はこれらを孤立超曲面に絞り、三変数のスタック・変形剛性を Hilbert 級数の極と算術 signature に置き換えた。v02 の更新は渡辺 arXiv 第1版との比較追記であり、全面的な再証明監査ではない。

## 既に訂正した誤解

1. **固定した式の行列式条件は内在的不変量ではない。** `x²+y³+z⁸` は `(12,8,3;24)`、a=1、det=48 だが根環を与える。`x²+xz⁴+y³` という det=24 の同型な表示を選べる。「適切な principal 可逆表示が存在する」を使う。
2. **可逆性の定義に孤立性が必要。** 項数=n、det≠0、正の重みだけで代用しない。原点が critical point であることも必要。
3. **正規形と同型類を区別する。** 指数行列の行列置換だけを商にしても、環の同型類分類にならない。
4. **Hilbert 級数の一致だけでは環同型でない。** v02 は元の T への単項式準同型を作り、単射性と Hilbert 関数から同型を得る。その独立した単射性を落とさない。
5. **孤立性だけで最大根にならない。** `(2,3,7,67)` は最大 index=25 だが、index=5 の Veronese 根環も原点以外で正則であり、超曲面ではない。高次元の最大根は孤立性に加えて超曲面性を使う。
6. **dim と n を取り違えない。** n=3 は環の次元2。n≥4 が高次元枝。
7. **有限性は n,a 両方固定。** a=1 の Sylvester 型の例は任意の n に存在する。
8. **数論の切り捨て減算に注意。** defect は ℤ で計算するか `h = a+sum w` を使う。負の defect を 0 に切り捨てて a=0 と解釈しない。

## 主張と新規性の扱い

三変数の可逆データからの主格子構成には Saito・Takahashi・Ebeling–Takahashi の先行研究がある。現稿の中心は任意の根環の超曲面表示から可逆表示を強制する方向であり、先行の構成を新発見と主張しない。未刊仕事との非重複も保証しない。Lean プロジェクトでは優先権の断定を増やす必要はない。

## 渡辺の比較は regression であって分類仕様ではない

比較対象は Kei-ichi Watanabe, arXiv:1401.0789v1, 2014-01-04, Section 3、本稿の三点型、1≤a≤6 に限定する。転記51件と現稿の57件との差は六つのキーである。

- a=3: (4,10,13;30)
- a=4: (5,6,9;24)
- a=5: (6,8,19;38), (4,7,16;32), (4,7,12;28), (4,7,9;25)

掲載誌版や後の訂正は逐項照合していない。一般有限性定理の誤りや、上記特異点自体の新発見を意味しない。CSV 転記の正確さを Lean の形式証明と混同しない。列挙器に「欠落六例を追加する」例外処理を書いてはならない。一般アルゴリズムから自然に出ることを検査する。
