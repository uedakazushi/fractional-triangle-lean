# Output format

`lake exe canonical_roots n a` returns JSON. Successful outputs have `status: "ok"`,
`input`, `count` and `equations`. All integral data are decimal strings, including
large coefficients, weights and exponents. An empty list is a successful result.
Invalid syntax or `n < 3` or `a < 1` yields `invalid_input` and exit status 2.

Each equation records its weights, relation degree, polynomial terms, signature,
root normal form and monomial realization witness. The polynomial terms are the
machine-readable mathematical data; the human-readable equation is a display.
Sorting variables simultaneously permutes the corresponding exponent columns and
monomial-map rows. Coefficients in the emitted representative are all +1.

The pure decoder reconstructs all fields of EquationData. Redundant fields such as
sorted signature, weight key and root displays are generated by the encoder but
are not authenticated as arbitrary input bytes by that round-trip theorem.
See `formal/CanonicalRoots/ClassificationPayloadCodec.lean` and the original detailed
schema in `docs/archive/OUTPUT_SCHEMA_ja.md`. Example payloads are under `samples/`.
